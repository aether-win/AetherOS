# AtlasDesktop toggles

Generated by `tools/dev/Export-AtlasCatalog.ps1` from the definitions under
`playbook/Executables/AtlasModules/Toggles`. Do not edit by hand; edit the definition and regenerate.

Toggles: 90. Elevation is the identity the machine work runs as; a toggle that records no state is a one-shot action.

## Advanced

### MicrosoftStore

Removes Microsoft Store for all users or restores it for your account, downloading its package from Microsoft when needed.

Elevation: Admin

> Disable removes Microsoft Store for every user on this PC. Enable restores it for your account only and may need an Internet connection.
